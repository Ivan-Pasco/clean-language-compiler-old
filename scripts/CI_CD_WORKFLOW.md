# COMITA - Automated CI/CD Workflow

Trigger: when the user types **"comita"**, execute this automated CI/CD workflow.

## Workflow Loop

```
REPEAT until CI passes:
  1. Stage & commit changes with descriptive message
  2. Push to remote (and tags if version changed)
  3. Calculate wait time from recent CI runs
  4. Wait for CI with progress updates every 2 minutes
  5. Check CI status
  6. IF FAILED → get logs, analyze, fix, GOTO REPEAT
  7. IF PASSED → cleen install latest, report success, EXIT
```

## Step 1: Commit and Tag

```bash
git add -A
git commit -m "fix: <auto-generated based on changes>"

VERSION=$(grep '^version' Cargo.toml | head -1 | sed 's/.*"\(.*\)"/\1/')
git tag -a "$VERSION" -m "Release $VERSION" 2>/dev/null || echo "Tag exists"

git push && git push --tags
```

## Step 2: Calculate Wait Time

```bash
gh run list --workflow=CI --limit=3 --json startedAt,updatedAt | \
  python3 -c "
import json, sys
from datetime import datetime
runs = json.load(sys.stdin)
if runs:
    durations = []
    for r in runs:
        start = datetime.fromisoformat(r['startedAt'].replace('Z', '+00:00'))
        end = datetime.fromisoformat(r['updatedAt'].replace('Z', '+00:00'))
        durations.append((end - start).total_seconds())
    avg = sum(durations) / len(durations)
    print(int(avg + 60))
else:
    print(1020)
"
```

## Step 3: Wait and Monitor

- Wait for the calculated duration (~17 minutes typical)
- Check CI status every 30 seconds in the final 2 minutes

## Step 4: Check CI Results

```bash
gh run list --workflow=CI --limit=1 --json conclusion,status,number
```

## Step 5: Handle Results

**If CI PASSES:**
```bash
cleen install latest
```

**If CI FAILS:**
```bash
gh run view <run-number> --log-failed
```
Then analyze the error, fix the issue, and repeat from Step 1.

## Rules

- Always wait for CI to complete — never skip
- Always fix root causes when CI fails
- Always provide progress updates during wait
- Always use semantic versioning for tags
- Never assume CI passed without checking
